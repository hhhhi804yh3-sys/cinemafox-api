# 🎬 Cinema Fox Cloud API & Series Aggregator Backend

سيرفر وسيط سحابي فائق السرعة ومبني خصيصاً لمنصة **Vercel** لخدمة تطبيق **سينما فوكس (Cinema Fox)**.

---

## 🚀 المميزات الرئيسية
1. **تجميع وفهرسة المسلسلات تلقائياً:** سحب عدد المواسم والحلقات الحقيقية بدقة 100% لأي مسلسل من خلال واجهات MovieBox الرسمية، دون أي تداخل بين الأجزاء المشابهة.
2. **كاش سحابي عالمي (Vercel Edge Caching):** تسريع استجابة التطبيق لأقل من 30 ميلي ثانية وتخفيف الضغط على سيرفرات البث.
3. **فلترة وحذف المحتوى غير اللائق (Adult Filter):** حظر أي محتوى إباحي أو تصنيفه Erotic/Adult أو مسميات خادشة على مستوى السيرفر قبل وصوله للتطبيق.
4. **توفير الترجمة العربية التلقائية:** جلب الترجمات العربية المتطابقة مع الحلقات.
5. **التحكم عن بُعد بدون الحاجة لتحديث APK:** إمكانية تعديل الإعلانات، الروابط، وقناة تليجرام في أي لحظة.

---

## 🛠 طريقة الرفع على Vercel (في دقيقة واحدة)
1. افتح حسابك على [Vercel](https://vercel.com).
2. اضغط **Add New Project**.
3. اختر مستودع GitHub هذا: `hhhhi804yh3-sys/cinemafox-api`.
4. اضغط **Deploy** مباشرة (لا يحتاج أي إعدادات خاصة).
5. ستحصل فوراً على دومين مثل: `https://cinemafox-api.vercel.app`.

---

## 📡 نقاط النهاية (API Endpoints)

| Endpoint | الوصف | مثال |
| :--- | :--- | :--- |
| `GET /api/home` | الواجهة الرئيسية (بنرات، سلاسل، أفلام، مسلسلات مفلترة) | `/api/home` |
| `GET /api/detail` | تفاصيل العمل مع المواسم والحلقات الدقيقة 100% | `/api/detail?subjectId=4622284752710778936&detailPath=dexter-resurrection-kkXwea17sv5` |
| `GET /api/search` | بحث حي دقيق مع دمج مواسم المسلسلات وحذف الإباحيات | `/api/search?q=Dexter` |
| `GET /api/streams` | روابط البث المباشر (1080p, 720p, 480p) مع الهيدرز | `/api/streams?subjectId=...&se=1&ep=1` |
| `GET /api/subtitles` | ملفات الترجمة العربية والإنجليزية للحلقة أو الفيلم | `/api/subtitles?subjectId=...&se=1&ep=1` |
| `GET /api/config` | إعدادات التطبيق الحية (تليجرام، إعلانات Start.io) | `/api/config` |
